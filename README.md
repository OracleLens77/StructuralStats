# StructuralStats

Библиотека для структурного статистического анализа на R, основанная на
методологии проф. К. Гатева и доц. Н. Гатевой («Бизнес статистика», гл. 9),
работах Л.С. Казинца, В.М. Рябцева, а также современных исследованиях
В.Н. Афанасьева (2019) и Н.П. Перстенёвой (2012).

## Установка

```r
# install.packages("devtools")
devtools::install_github("<your_username>/StructuralStats")
```

## Возможности

### 1. Коэффициенты структурных сдвигов и различий

```r
library(StructuralStats)

# Доли затрат на топливо: 2008 и 2018 гг. (Афанасьев, 2019, табл. 1)
d_2008 <- c(0.58, 0.42)  # Топливо, Остальное
d_2018 <- c(0.83, 0.17)

gatev_integral(d_2008, d_2018)     # интегральный коэффициент Гатева
ryabtsev_index(d_2008, d_2018)     # индекс Рябцева
kazinetz_linear_abs(d_2008, d_2018)
```

Проверочный пример из учебника Гатева и Гатевой (структура экспорта фирмы
по группам стран, 2002 vs 2007):

```r
v2002 <- c(0.30, 0.40, 0.20, 0.10)
v2007 <- c(0.60, 0.20, 0.15, 0.05)

gatev_linear_norm(v2002, v2007)    # 0.30
gatev_quadratic_norm(v2002, v2007) # 0.26
gatev_integral(v2002, v2007)       # 0.43
```

### 2. Неравномерность распределения

```r
income_shares <- c(0.05, 0.10, 0.15, 0.20, 0.50)
gini_coefficient(income_shares)
lorenz_curve_data(income_shares)
```

### 3. Индексы цен и объёмов

```r
p0 <- c(10, 20, 30); p1 <- c(12, 25, 35)
q0 <- c(100, 50, 20); q1 <- c(110, 60, 15)

laspeyres_index(p0, p1, q0)
paasche_index(p0, p1, q1)
fisher_index(p0, p1, q0, q1)
```

### 4. Прогнозирование (адаптивные методы)

```r
costs <- c(100, 105, 110, 108, 112, 115)
simple_exponential_smoothing(costs, alpha = 0.3)
holt_smoothing(costs, alpha = 0.3, beta = 0.1)
```

### 5. Ранговые корреляции

```r
spearman_correlation(c(1, 2, 3, 4), c(1, 3, 2, 4))
kendall_concordance(matrix(c(1, 2, 3, 1, 3, 2, 2, 1, 3), nrow = 3))
```

### 6. Меры вариации (Гатев, Гатева, гл. 3)

```r
x <- c(520, 560, 600, 640, 680, 720, 760, 800)  # зарплаты, окт. 2008
f <- c(10, 19, 27, 38, 46, 35, 24, 12)

variation_range(x)             # размах
mean_abs_deviation(x, f)       # среднее линейное отклонение, 59.81
weighted_sd(x, f)              # sd и дисперсия, 72.48 / 5253.29
coef_variation_sigma(x, f)     # коэффициент вариации по sigma, %
binary_sd(0.3)                 # sd альтернативного признака
quartile_deviation(x)          # квартильное отклонение Боули
```

### 7. Интенсивность структурных сдвигов (Афанасьев, формулы 10-18)

```r
d0 <- c(0.3, 0.4, 0.3); dt <- c(0.5, 0.3, 0.2)

oscillation_coef(d0, dt)         # коэффициент колеблемости
variation_coef_shifts(d0, dt)    # коэффициент вариации сдвигов
linear_intensity(d0, dt)         # линейная мера интенсивности
correlation_intensity(d0, dt)    # корреляционная мера интенсивности

seasonality_coef(c(85, 95, 110, 130, 105, 90, 88, 92, 98, 115, 120, 72))
```

## Теоретическая база

- Гатева Н., Гатев К. Бизнес статистика — гл. 3 «Емпирични статистически разпределения» (мерки на вариацията) и гл. 9 «Структурен статистически анализ».
- Казинец Л.С. Темпы роста и структурные сдвиги в экономике. М., 1981.
- Перстенёва Н.П. Критерии классификации показателей структурных различий и сдвигов // Фундаментальные исследования. 2012. №3. С. 478–482.
- Афанасьев В.Н. Статистические методы в исследовании изменений структуры и элементов затрат на производство электроэнергии // Вестник НГУЭУ. 2019. №4. С. 286–303.
